# Protocol Zoo 中文导览

欢迎来到 Protocol Zoo（协议动物园）。本仓库是一座**能通电的网络协议博物馆**：用历史资料、成熟实现、隔离实验、抓包、日志和明确的证据边界，观察网络协议为什么诞生、如何存活，以及为什么退出主流。

这不是把所有英文技术词强行翻成中文的“译本”。协议名、RFC 编号、命令、路径、JSON/pcap 字段等可执行或可检索标识会保留原文，中文负责解释它们在网络里做什么、证据能证明到哪里。

## 证据等级

- `L0`：仅有规范或文献引用；
- `L1`：合成 fixture；
- `L2`：可执行的本地复现，但没有数据包级证据；
- `L3`：本地隔离环境中的数据包级证据；
- `L4`：受控真实公网（WAN）证据；
- `L5`：外部独立佐证。

使用 VPS **不会自动**把证据升级为 `L4`。公网观察只代表特定时间、路径和端点，不能推广成整个互联网的普遍结论。

## 如何复现实验

```bash
# 全库基础检查
make check

# 第三纪元验证
./scripts/era3-validate.sh

# DNS：委派、glue、递归、缓存、TTL、NXDOMAIN
./scripts/experiment.sh era3-dns

# HTTP/1.0、HTTP/1.1 与 TLS 可见性
./scripts/experiment.sh era3-http-tls

# GRE 外层/内层封装
./scripts/experiment.sh era3-gre

# PMTUD 与已知拓扑中的 UDP/ICMP traceroute
./scripts/experiment.sh era3-path

# 第二纪元验证（不会重录既有证据）
./scripts/experiment.sh era2-validate
```

实验默认只使用 loopback、network namespace、veth、私有保留地址和合成数据。不要把 Telnet、FTP、rlogin、rsh 或其他弱认证服务暴露到公网。

## 阅读约定

中文说明会保留以下原文，因为它们是可执行或可检索的技术标识：协议名、RFC 编号、命令、路径、JSON 字段、pcap 字段和工具输出。正文中的英文术语首次出现时尽量给出中文解释。

`real-capture`、`fixture`、`static`、`document-reconstruction`、`not-run` 是仓库的证据标签，不是“完成/失败”的简单二元评分。没有真实抓包的内容不会写成真实抓包结论。

## 常用术语速查

| 原文 | 中文理解 | 在本仓库里通常指什么 |
|---|---|---|
| packet | 数据包 | 网络层或传输层正在传递的一份协议数据 |
| frame | 帧 | 链路层观察到的一次传输单元；抓包表常按 frame 编号 |
| capture / pcap / pcapng | 抓包 / 抓包文件 | `tcpdump`、Wireshark、tshark 保存的原始网络证据 |
| fixture | 可控合成样本 | 为展示某个协议机制而生成的最小样本，不冒充真实部署 |
| network namespace / netns | 网络命名空间 | Linux 中隔离接口、地址、路由和进程网络视图的实验环境 |
| endpoint | 端点 | 通信真正开始或终止的主机、进程或协议实体 |
| middlebox | 中间盒 | 位于通信路径中的 NAT、防火墙、代理、负载均衡器等设备或功能 |
| TCP stream | TCP 流 / 会话流 | 抓包工具把属于同一条 TCP 连接的报文归在一起的观察单位 |
| reverse proxy | 反向代理 | 接收客户端连接，再以另一条连接访问后端 origin 的代理 |
| ClientHello | 客户端握手问候 | TLS 握手中客户端首先声明版本、能力等信息的消息之一 |
| ALPN | 应用层协议协商 | TLS 握手中协商 HTTP/1.1、HTTP/2 等上层协议的扩展机制 |
| outer / inner | 外层 / 内层 | GRE 等隧道中负责运输的外层包与被封装的内层包 |
| MTU | 最大传输单元 | 一条链路一次能够承载的最大 IP 包尺度约束 |
| PMTUD | 路径 MTU 发现 | 端点寻找整条路径可承载最大包大小的机制 |
| traceroute | 路径逐跳探测 | 利用 TTL/Hop Limit 与返回消息观察路径中各跳的工具/方法 |
| ground truth | 已知真实拓扑 | 实验者事先知道的受控拓扑，用来判断 traceroute 等观察是否对应真实路径 |

看到英文术语时不必先把它“翻译干净”再继续读。最重要的是知道：它在哪一层、改变了什么、抓包里能看到什么、当前证据能证明到哪里。
