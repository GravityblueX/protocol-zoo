# Protocol Zoo 中文导览

欢迎来到 Protocol Zoo（协议动物园）。本仓库是一座**能通电的网络协议博物馆**：用历史资料、成熟实现、隔离实验、抓包、日志和明确的证据边界，观察网络协议为什么诞生、如何存活，以及为什么退出主流。

## 证据等级

- `L0`：仅有规范或文献引用；
- `L1`：合成 fixture；
- `L2`：可执行的本地复现，但没有数据包级证据；
- `L3`：本地隔离环境中的数据包级证据；
- `L4`：受控真实公网（WAN）证据；
- `L5`：外部独立佐证。

使用 VPS **不会自动**把证据升级为 `L4`。公网观察只代表特定时间、路径和端点，不能推广成整个互联网的普遍结论。

## 如何复现实验

```bash
# 全库基础检查
make check

# 第三纪元验证
./scripts/era3-validate.sh

# DNS：委派、glue、递归、缓存、TTL、NXDOMAIN
./scripts/experiment.sh era3-dns

# HTTP/1.0、HTTP/1.1 与 TLS 可见性
./scripts/experiment.sh era3-http-tls

# GRE 外层/内层封装
./scripts/experiment.sh era3-gre

# PMTUD 与已知拓扑中的 UDP/ICMP traceroute
./scripts/experiment.sh era3-path

# 第二纪元验证（不会重录既有证据）
./scripts/experiment.sh era2-validate
```

实验默认只使用 loopback、network namespace、veth、私有保留地址和合成数据。不要把 Telnet、FTP、rlogin、rsh 或其他弱认证服务暴露到公网。

## 阅读约定

中文说明会保留以下原文，因为它们是可执行或可检索的技术标识：协议名、RFC 编号、命令、路径、JSON 字段、pcap 字段和工具输出。正文中的英文术语首次出现时尽量给出中文解释。

`real-capture`、`fixture`、`static`、`document-reconstruction`、`not-run` 是仓库的证据标签，不是“完成/失败”的简单二元评分。没有真实抓包的内容不会写成真实抓包结论。
