# 第二纪元来源索引

| 主题 | 权威来源 |
|---|---|
| RARP | RFC 903 |
| BOOTP | RFC 951 |
| TFTP | RFC 1350 |
| SLIP | RFC 1055 |
| CSLIP/VJ compression | RFC 1144 |
| PPP framing/LCP | RFC 1661 |
| PPP PAP/CHAP | RFC 1334, RFC 1994 |
| RIP | RFC 1058, RFC 2453 |
| EGP | RFC 904 |
| ICMP Source Quench deprecation | RFC 6633 |
| NetBIOS | RFC 1001, RFC 1002 |
| IPv6 transition | RFC 2529, RFC 3053, RFC 4380, RFC 6343, RFC 7526 |
| ARPANET Host-Host/NCP context | RFC 714 |
| rlogin | RFC 1282 |
| multicast/IGMP | RFC 1112, RFC 2236 |
| DVMRP/PIM | RFC 1075, RFC 3973 |

博客或搜索摘要只能作为线索，不能替代上述规范。外部 pcap 另需来源、许可证、日期和 SHA-256。
